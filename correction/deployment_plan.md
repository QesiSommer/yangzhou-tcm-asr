# 部署方案：极限边缘端 SLM 本地化落地方案

## 一、部署环境与物理约束

本模块最终部署目标为**医院诊室终端电脑**，其物理条件极为苛刻：

| 约束项 | 参数 |
|--------|------|
| CPU | 老旧 Intel CPU（无独显，纯 CPU 推理） |
| 内存 | 4GB ~ 8GB（操作系统 + 应用 + 模型 共享） |
| 网络 | **严格物理断网** — 仅局域网，绝对禁止外网 API 调用 |
| 延迟要求 | 流式问诊场景，推理延迟需控制在 **1~2 秒内** |

## 二、技术选型：Ollama + Qwen2.5 1.5B

### 为什么是 Ollama

- **纯离线**：模型下载后可永久离线运行，零外网依赖
- **Windows 原生支持**：一键安装，无需 Docker/WSL，适配医院常见的 Windows 诊室终端
- **OpenAI 兼容 API**：现有 `llm_client.py` 仅需改 `base_url` 和 `model` 两个参数
- **CPU 推理优化**：Ollama 内置 llama.cpp 后端，纯 CPU 推理效率高

### 为什么是 Qwen2.5 1.5B 而非更大模型

| 模型 | 参数量 | 内存占用 | CPU 推理延迟（单次） | 结果 |
|------|--------|----------|---------------------|------|
| `qwen3:8b` | 8B | ~6GB | 30~60 秒 | ❌ OOM + 不可用 |
| `qwen3:4b` | 4B | ~3.5GB | 10~20 秒 | ❌ 内存紧张 + 延迟太高 |
| `qwen2.5:3b` | 3B | ~2.5GB | 5~10 秒 | ❌ 延迟仍超标 |
| **`qwen2.5:1.5b`** | **1.5B** | **~1.2GB** | **0.5~2 秒** | **✅ 完美适配** |

### 小模型的"智商缺陷"如何弥补？

这正是本项目的核心创新——**N-best Closest 约束解码架构**：

```
ASR N-best 候选 → 词典加权 → 小模型自由推理 → 编辑距离映射 → 最终物理约束输出
```

1. **词典加权**（`check_tcm_dict`）：50+ 中医专业术语词典，含药材、证候、方剂、脏腑等关键词。即使小模型未能正确纠错，词典加分可将含正确术语的候选句拉高。
2. **编辑距离约束**（`levenshtein_distance`）：小模型的输出仅作为"语义参考方向"，不直接作为最终结果。最终输出**严格来自 ASR 物理候选路径**，从源头杜绝幻觉。
3. **权重可调**（`w1/w2/w3`）：可根据实际场景微调 ASR 置信度、词典加分、编辑距离三者的权重配比。

**结论**：1.5B 模型提供"语义指导"（判断哪个方向更合理），词典和编辑距离做"物理约束"（确保输出不越界），两者互补，足以在中医问诊这个垂直场景中达到实用精度。

## 三、安装与部署流程

### Step 1: 安装 Ollama（离线方式）

由于诊室终端断网，需提前在联网环境下载离线安装包和模型文件，通过 U 盘/局域网传输。

**方案 A — 安装包 + 模型导出**：
```bash
# 在联网机器上
winget install Ollama.Ollama
ollama pull qwen2.5:1.5b

# 导出模型为 tar 文件
ollama save qwen2.5:1.5b -o qwen25_1.5b.tar

# 在诊室终端上
ollama load -i qwen25_1.5b.tar
```

**方案 B — 直接拷贝 Ollama 模型目录**：
```
联网机器: %USERPROFILE%\.ollama\models\
           ↓ (U盘拷贝)
诊室终端: %USERPROFILE%\.ollama\models\
```

### Step 2: 验证离线运行

```bash
# 确认模型已加载（无需网络）
ollama list
# 应输出: qwen2.5:1.5b  ...

# 离线推理测试
ollama run qwen2.5:1.5b "将'需要荡鬼调理'纠正为正确的中医术语"
```

### Step 3: 启动本模块

```bash
cd TCM_Correction
python error_correction.py
```

## 四、配置清单

当前 `llm_client.py` 默认配置已更新为：

| 配置项 | 值 | 说明 |
|--------|-----|------|
| `base_url` | `http://localhost:11434/v1` | Ollama 默认 API 地址 |
| `model` | `qwen2.5:1.5b` | 1.5B 参数极限轻量模型 |
| `timeout` | `30.0` 秒 | CPU 推理超时容忍 |

## 五、性能预期

| 指标 | 预期值 |
|------|--------|
| 模型加载后内存占用 | ~1.2GB |
| 单次推理延迟 | 0.5 ~ 2 秒 |
| 纠错准确率（扬州方言场景） | 依赖 N-best Closest 约束，预期 >85% |
| 幻觉发生率 | 0%（输出严格来自 ASR 候选路径） |

## 六、降级兜底策略

即使 Ollama 服务未启动或模型不可用，`llm_client.py` 的 `generate_correction()` 方法也会自动降级返回原始 ASR 1-best 文本。此时系统退化为纯词典 + ASR 置信度打分模式，仍能完成部分纠错（命中词典的候选句获得加分）。
